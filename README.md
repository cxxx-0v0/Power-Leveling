# 星图加点 · Power Leveling

Minecraft 1.20.1 / Forge 47.x / Java 17 的近战战斗成长模组。当前发布：**0.1.0 内测一版**。

本仓库仅提供模组二进制发布，不包含模组源码。请从 [Releases](https://github.com/cxxx-0v0/Power-Leveling/releases) 下载 JAR。

## 安装

将发布页中的 `powerlevel-0.1.0.jar` 放入客户端和服务端的 `mods` 文件夹。需要 Minecraft 1.20.1、Forge 47.x 和 Java 17。

本版本还要求两端安装 `Particle 0.5.3-1.20.1`（mod id：`particle`）。该附属为第三方作品，许可标注为 All Rights Reserved，本仓库不重新分发；请从其作者或整合包提供方获取。`Powercards` 为可选卡源，不安装时使用模组内置卡牌。
